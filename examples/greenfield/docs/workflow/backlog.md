# Backlog

只记归属，不记状态。进度写在切片文件里，这样最频繁的写入只碰一个单人独占的文件。

| A-ID | slice | note |
| --- | --- | --- |
| A-01 | S-01 | |
| A-02 | S-01 | |
| A-03 | - | 未认领；等 S-01 的输出格式定下来再开 S-02 |
| A-04 | deferred | 变更记录 docs/changes.md#C-01 |
| A-05 | dropped | 取消，变更记录 docs/changes.md#C-02 |

这五行必须与 `docs/contract.md` 的「验收场景」表逐个相等：少一行、多一行、重复 ID 都会让脚本
拒绝给出完成判定。A-04 延后、A-05 取消，两条都仍占一行——归属变了，承诺没有消失。

`deferred` 和 `dropped` 的区别只在会不会重开：C-01 写得出重开条件，C-02 写不出。两者的 note
都必须指向变更记录，因为脚本不管你以后打不打算做，只管这次不做是一个有出处的决定。
